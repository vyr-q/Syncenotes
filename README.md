# Lockport Map — Windows starter

## Run
1. Install VS Code.
2. Open this folder.
3. Install the VS Code extension **Live Server**.
4. Right-click `index.html` → **Open with Live Server**.

The starter includes a Lockport map, guest suggestion form, and a basic admin page.

## Important
This first version uses browser localStorage, so it is a prototype rather than a secure public service. Before publishing, replace localStorage with Firebase (or another hosted database), add real admin authentication, and add image uploads. The map uses OpenStreetMap tiles through Leaflet.
